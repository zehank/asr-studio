# Studio · 转文字 / 翻译 / 总结

一个本地网页，拖进音频或视频，勾选要做的处理，点一次就全跑完。

## 启动

```bash
cd ~/Documents/deepseek-harness/default-workspace/studio
./start
```

会自动打开 <http://127.0.0.1:8770>。关掉终端窗口就停了。

## 用法

1. 把音频/视频拖进框里（可一次拖多个，或点击多选）。每个文件一行，各自有进度、状态和取消按钮。
2. 勾选 **翻译**、**总结**（转文字永远执行）。
3. 识别语言默认「自动」，中英混说也能处理。
4. 点「开始处理」，进度条走完，结果分三块出来：文字 / 翻译 / 总结，都能一键复制、下载。

结果同时落在 `studio/output/<时间-文件名>/` 里：
`text.txt`、`<文件名>.srt`、`translation.txt`、`summary.md`。

## 背后用的是什么

| 步骤 | 服务 | 费用 |
|---|---|---|
| 转文字 | whisper.cpp + large-v3-turbo，本地 Metal GPU | 免费，不上传 |
| 翻译 | Google 翻译免费接口（`clients5` / `gtx` 两个入口轮试），挂了退 MyMemory | 免费，无需 key |
| 总结 | 可在页面上切换：DeepSeek API / Gemini / 本地 Ollama / 免费公共接口 | 前三个要 key 或本地模型；最后一个免费但每 45 秒 1 次 |

依赖：只用 macOS 自带的 Python 3.9 标准库，不需要 `pip install` 任何东西。

## 已知限制

- 翻译是逐段调接口（单块 ≤1000 字，超长单行会硬切），长文件要等一会儿；Google 限流时自动换入口或退 MyMemory。
- 总结默认走免费公共接口，**每 IP 45 秒才允许 1 次**，会显示「等 N 秒」，1 小时讲座约 3–5 分钟。
  换成 DeepSeek API（按 token 计费，一条讲座几分钱）就没有这个等待，1 小时讲座一次调用直接出结果。
  key 存在 `studio/config.json`（权限 600），页面「总结用」右边粘贴后点保存。
- 翻译或总结失败不会拖垮整次任务：文字照常输出，界面顶部黄条会写清哪一步失败。
- 音频识别误差会原样传给翻译和总结，术语可以回 `audio2text/trans --terms` 那条路单独跑。
