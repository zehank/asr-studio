# trans —— 本地音频/视频转文字（中文 + 英文）

不用联网、不花钱、不到云端。底层是开源的 **whisper.cpp**（OpenAI Whisper 的 C++ 移植版），
模型跑在这台 Mac 的 GPU 上（Metal）。

## 用法

```bash
cd ~/Documents/deepseek-harness/default-workspace/audio2text

./trans 录音.m4a                     # 中英自动识别，出 录音.txt + 录音.srt
./trans 讲座.mp4                     # 视频也能直接喂
./trans a.m4a b.mp3 -l zh            # 多个文件，强制中文
./trans 录音.m4a --terms "丙酮酸,线粒体,ATP"   # 专业词提示，术语更准
./trans 录音.m4a -o ~/Desktop        # 输出到别处
```

输出：`<文件名>.txt`（纯文本，可直接复制）/ `<文件名>.srt`（带时间轴字幕，能拖进播放器）。

## 参数

| 参数 | 说明 |
|---|---|
| `-l zh/en/auto` | 识别语言，默认 `auto`（中英混说用它） |
| `-m turbo/small/base` | 模型，默认 `turbo`（1.6 GB，4 层解码器，速度和 small 差不多但准得多） |
| `--terms "词,词"` | 术语提示，明显改善专业名词；也可能引入尾部幻觉，不强求别用 |
| `-o 目录` | 输出目录 |
| `-q` | 屏幕上不打印正文 |
| `-t N` | 线程数 |

## 支持的输入

`m4a / mp3 / wav / flac / ogg / aac` 直接读；`mp4 / mov / m4v` 先用 `avconvert` 抽音轨。
任何 QuickTime 能播的格式基本都能进。

## 速度（这台机器，M 系列 + Metal）

| 音频 | turbo | small |
|---|---|---|
| 32 秒中文 | 8.1 s | 7.4 s |

大约 4 倍实时：1 小时录音 ≈ 15 分钟。

## 原理

1. **切窗**：音频重采样成 16 kHz 单声道，切成 30 秒的小段（whisper 的输入窗口）。
2. **听特征**：每段算一条 80/128 维的 log-Mel 声谱图（相当于给声音做"频谱照片"）。
3. **编码器**：卷积 + 自注意力把声谱图压成一组特征向量，这一段就是"听懂的中间表示"。
4. **解码器自回归出字**：一个字一个字往外吐（token），每步在 5 万多个 token（字母/汉字片段/BPE）里
   选概率最高的那个；再用 beam search 保留几条候选路径、用时间戳对齐把 token 落到秒。
5. **语言自动判别**：编码器特征先过一个语言分类头，判断这段是中文还是英文，再选对应解码路径。
6. **收尾**：`-l zh` 时中文常用字词更集中；后处理把汉字间的空格删掉、半角标点换成全角。

## 局限

- 术语、人名、缩写（尤其被念成字母的 ATP / pH）最容易错，`--terms` 能救一部分。
- 背景音乐大、方言、口音重时准确率下降；这是模型能力上限，不是参数没调对。
- 纯静音/纯音乐段偶尔会硬吐一句话（幻觉），长录音里看到莫名其妙的一行，删掉即可。
